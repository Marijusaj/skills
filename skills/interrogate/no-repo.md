# /interrogate: no-repo mode

Read before round 1 when the goal is not a change to a codebase (a decision,
a purchase, a trip, a talk) or the owner says `no repo`. Every step in
`SKILL.md` runs; these replace their repo parts.

| Step | Instead |
|---|---|
| 1 research | the files the owner points at, and the web, via subagent |
| 2 grill the language | still grill fuzzy words; no glossary file |
| 3 capture | a **Decided so far** block at the top of each round message: one line per answer, with what was rejected. Write it to a file only when the owner asks |
| 4 design | skip design-check; the builder check reads the Decided block as the person who must carry the plan out |
| 5 plan | end with the Decided block and the next actions, each with who does it and by when. Nothing gets built |

**Done when** the owner has the Decided block, every builder question is in a
pile, and each next action names who and when.
